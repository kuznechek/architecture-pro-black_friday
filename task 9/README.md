# Задание 9. Настройка чтения с реплик и консистентность

1. Для коллекций products и orders и carts определите:

- Какие операции чтения могут использовать secondary реплику для чтения.
- Какие операции чтения должны читать только с primary.
- Укажите, какая задержка репликации допустима для операций на secondary.

2. Обоснуйте выбор, опираясь на:
- Требования к консистентности данных.
- Частоту обновлений.
- Бизнес-логику (например, риск продажи недоступного товара или отображение устаревшего статуса заказа пользователю).

## Products

| Операция                                                    | Primary/Secondary | Комментарий                      | Задержка |
|-------------------------------------------------------------|-------------------|----------------------------------|----------|
| Частые обновления остатков при покупках                     | Primary           | Необходима актуальная информация |          |
| Поиск товаров                                               | Secondary         | Товары обновляются не часто      | 1-5 c    |
| Описание товара                                             | Secondary         | Товары обновляются не часто      | 1-3 c    |

## Orders

| Операция                                                    | Primary/Secondary | Комментарий                           | Задержка |
|-------------------------------------------------------------|-------------------|---------------------------------------|----------|
| Быстрое создание заказов с одновременным списанием остатков | Primary           | Данные обновляются в реальном времени |          |
| Поиск истории заказов конкретного пользователя              | Secondary         | Истории заказов обновляются не часто  | 1-5 c    |
| Отображение статуса заказа                                  | Primary           | Необходима актуальная информация      |          |

## Carts

Корзина является постоянно актуальной составляющей профиля пользователя. Задержки недопустимы, вся информация должна быть доступна в реальном времени.

| Операция                                                                   | Primary/Secondary | Комментарий                      |
|----------------------------------------------------------------------------|-------------------|----------------------------------|
| Создание корзины, когда заходит гость или новый пользователь               | Primary           | Необходима актуальная информация |
| Получение текущей корзины по фильтру                                       | Primary           | Необходима актуальная информация |
| Добавление или замена товара в корзине                                     | Primary           | Необходима актуальная информация |
| Удаление товара из корзины                                                 | Primary           | Необходима актуальная информация |
| Слияние гостевой корзины в пользовательскую, если пользователь залогинится | Primary           | Необходима актуальная информация |
| Отметка корзины как заказанной                                             | Primary           | Необходима актуальная информация |
